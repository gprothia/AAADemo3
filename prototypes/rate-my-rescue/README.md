# Rate My Rescue

A static clickable prototype showing how an AAA member could rate a roadside rescue and see top-rated drivers:

- **Rescue list**: Pick any rescue to rate — including completed rescues and ones still en route.
- **Rate a rescue ("How did we do?")**: Choose 1–5 stars, tap quick feedback tags (`On time`, `Friendly driver`, `Explained the fix`), and add an optional comment.
- **Thank-you screen**: Confirms the submitted rating and lets the member rate another rescue or jump to the leaderboard.
- **Top drivers this month**: A public leaderboard showing ranked drivers, driver photos, average stars, and top praise tags.

All data is fake and runs client-side with plain HTML, CSS, and JavaScript (no backend calls).
